# Meso 商业授权说明

## 为什么需要商业授权？

Meso 采用 BSL 1.1 许可证。在 2029-01-01 转为 Apache 2.0 之前，将 Meso 用于特定商业场景需要获得书面授权。商业授权收入支持项目持续研发与维护。

---

## 哪些场景需要商业授权？

| 场景 | 是否需要授权 |
|------|-------------|
| 个人学习、研究、实验 | ✅ 免费 |
| 内部工具（不对外服务） | ✅ 免费 |
| 开源项目（非商业） | ✅ 免费 |
| 教育、学术用途 | ✅ 免费 |
| 概念验证 / POC | ✅ 免费 |
| 对外提供的 SaaS 产品 | ⚠️ 需要授权 |
| 向客户销售的商业软件 | ⚠️ 需要授权 |
| 托管服务 / Managed Service | ⚠️ 需要授权 |
| 基于 Meso 的竞争性平台 | ⚠️ 需要授权 |

---

## 授权方案

### 独立开发者 / 小型团队（≤5人）

适合初创公司或小型团队将 Meso 集成到商业产品中。

- 授权范围：单一商业产品，生产环境部署
- 价格：**联系议价**
- 包含：12 个月技术支持邮件响应

---

### 企业授权

适合中大型企业或多产品线集成。

- 授权范围：组织范围内无限产品
- 价格：**联系议价**
- 包含：优先技术支持、定制集成咨询、SLA 协议

---

### OEM / 平台集成

适合将 Meso 嵌入自有平台或产品并向下游分发的场景。

- 授权范围：按需定制
- 价格：**联系议价**
- 包含：源码访问权、集成技术支持、品牌使用指引

---

## 如何获取授权？

请发送邮件至 **jacer.huang@gmail.com**，说明：

1. 公司 / 项目名称
2. 使用场景描述（产品类型、用户规模、部署方式）
3. 团队规模

我们将在 5 个工作日内回复。
