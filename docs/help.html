Composer 联动 不同应用可以配置不同的 Composer 工具栏。\`actions\` 字段支持以下预置动作： | 动作 | 说明 | |---|---| | upload | 文件上传按钮（支持拖拽）| | template | 快速模板选择器 | | search | 知识库搜索触发 | | code | 代码输入模式切换 | | voice | 语音输入（实验性）| ## 工具注册 工具在后端定义，Manifest 中通过 ID 引用。平台在流式响应中支持 \`tool_call\` 和 \`tool_result\` 事件类型（扩展协议，核心协议不含此字段）。 [应用插件演示](demo:09-plugin.html) [App Manifest 结构](demo:09-plugin.html#manifest)` }, { id: 'integration', label: '接入指南', icon: ``, content: `# 接入指南 本节提供新项目从零开始接入 Meso 平台的完整步骤，以及从 AI-KA 迁移的指南。 ##
